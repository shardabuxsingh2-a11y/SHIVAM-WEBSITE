# Shivam Patel Sports Media website

A responsive static website starter for a sports media and fan community.

## Files
- `index.html` — home page
- `about.html` — about the initiative
- `services.html` — sports information and community services
- `contact.html` — contact details placeholders
- `privacy.html` — privacy-policy starter draft
- `terms.html` — terms-of-use starter draft
- `style.css` — shared responsive design
- `script.js` — mobile navigation

## Before publishing
1. Replace placeholder phone, email, address and business-registration information with accurate details.
2. Remove any metrics or claims you cannot substantiate. This template intentionally avoids invented audience statistics.
3. Review the privacy policy and terms so they accurately describe your real data practices, forms, cookies, analytics and messaging.
4. Use only logos and images you have rights to use. The sample sports photos load from Unsplash and require an internet connection.
5. A website or this template does not guarantee Meta verification, WhatsApp approval, a green tick, or ad approval.

## GitHub Pages
Upload the files to a GitHub repository. In the repository, open **Settings → Pages**, select the deployment source/branch as appropriate, and publish. Connect your custom domain through GitHub Pages settings and configure DNS at your domain provider.


## Udyam certificate
The uploaded certificate PDF is included at `assets/udyam-registration-certificate.pdf` and linked from the Home and About pages. The website shows a summary of details transcribed from the uploaded certificate. Review all details before publishing.
